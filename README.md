# Desktop2Proxy (локальный клиент)

Простое десктоп‑приложение для хранения списка узлов (IP, логин, пароль) в файле и быстрого подключения.

Возможности:
- Добавление/редактирование записей (IP, логин, пароль)
- **Автоматическое сканирование сети**:
  - Определение открытых портов
  - Детекция операционной системы по портам
  - Подбор учетных данных (SSH/RDP/HTTP)
- Проверка доступности и автоопределение протокола (SSH/RDP/HTTP)
- Показ деталей (протокол, ОС, порты) по одиночному клику
- Двойной клик для открытия подключения системными средствами:
  - SSH: `ssh` (Windows: OpenSSH в PowerShell или `plink`)
  - RDP: `mstsc` (Windows)
  - HTTP/HTTPS: открытие в браузере
- Данные хранятся в файле `data/hosts.json`

## Установка
1) Установите Python 3.10+
2) Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск
```bash
python app.py
```

## Как пользоваться
- Нажмите «＋» чтобы добавить запись. 
- **Для автоматического сканирования**: введите IP и нажмите «🔍 Сканировать сеть»
  - Приложение просканирует порты, определит ОС и попробует подобрать логин/пароль
  - Результаты автоматически заполнят поля формы
- В списке рядом с IP появится ✔ или ✖ — доступность и протокол определяются автоматически
- 🔍 означает, что узел был просканирован nmap
- Одиночный клик по записи — детали справа (протокол, ОС, порты, статус сканирования)
- Двойной клик — подключение:
  - RDP (Windows): запустится `mstsc /v:IP`, учётка добавляется через `cmdkey`
  - SSH: при наличии `plink` пароль передаётся автоматически, иначе откроется `ssh` (пароль нужно ввести)
  - HTTP/HTTPS: откроется браузер. Если указан логин/пароль, они будут подставлены в URL
- Контекстное меню по правому клику: изменить/удалить запись
- **Кнопка "🔧 Исправить RDP"** - автоматически исправляет проблемы с RDP подключениями:
  - Отключает проверку CredSSP (AllowEncryptionOracle=2)
  - Отключает NLA (Network Level Authentication) - исправляет ошибку 0xb09
  - Обходит проверку сертификатов
  - Настраивает минимальный уровень шифрования
  - Отключает предварительную аутентификацию
  - Исправляет ошибки "указанная функция не поддерживается", "токен неправилен" и "требует проверки подлинности на уровне сети"

## Пакетное добавление (Bulk)
- Кнопка "📥 Пакетно" вверху
- Вставьте списки IP, логинов и паролей (каждый с новой строки)
- Нажмите "Старт подбора" — приложение для каждого IP:
  - просканирует порты и определит предполагаемую ОС
  - попробует логины/пароли для SSH/RDP/HTTP
  - при успехе добавит запись в список с галочкой и сохранит найденные данные

## Папки
- `data/hosts.json` — список узлов
- `assets/` — иконки (необязательно)

## Примечания и безопасность
- Файл `hosts.json` хранит пароли в открытом виде. Используйте на доверенных машинах.
- Для RDP требуется Windows. Для SSH желательно установить `PuTTY` (plink) либо OpenSSH.
- **Сканирование портов** работает без дополнительных зависимостей
- Подбор паролей использует стандартные словари (admin, password, 123456 и т.д.)
- Используйте только на собственных сетях или с разрешения владельца!
